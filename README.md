Personal CV Website

Project Overview:
A personal CV website developed as part of university coursework, using HTML, CSS and JavaScript to present my qualifications, skills, interests and professional experience.

Technologies Used:
- HTML — Website structure and content
- CSS — Styling, layout and responsiveness
- JavaScript — Interactive features and theme switching

Features:
- Multiple pages displaying personal and academic information
- Light and dark mode functionality
- Responsive layout
- Accessibility and usability considerations
- Progressive Web App functionality developed through a web manifest and service worker

Project Purpose:
This project provided an opportunity to apply front-end web development knowledge, explore user experience principles and gain practical experience building a multi-page website.

Known Limitations:
Some features may require further testing or refinement.
